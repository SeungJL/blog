첫 글을 발행하고 사이트를 열어봤다. 글은 있는데 디자인이 없었다.

직접 만든 CSS가 170줄이었고 다크모드도, 반응형도, 트랜지션도 없었다. 프론트엔드 개발자가 쓰는 블로그인데 디자인 자체가 신호가 되는 자리에서 골격만 있는 상태였다. 검증된 테마를 가져오는 게 낫다고 판단했다.

## 목록을 보고 골랐다

AstroPaper를 골랐다. 근거는 이랬다.

- 우리가 이미 쓰던 구조와 설계가 거의 같다 — Content Collections, `draft` 플래그, 태그, 필수 필드 검증. 글을 그대로 옮길 수 있다
- 요구 사양이 맞는다 — Astro 7.0.3 이상, Node 22.12 이상
- 필요한 게 다 들어 있다 — RSS, sitemap, OG 이미지 자동 생성, 검색, 태그, 아카이브, 다크모드

계획해둔 다음 단계가 통째로 해결되는 선택이었다. 적용했다. 99개 파일이 바뀌었다.

**이 근거들에는 공통점이 있다. 전부 README를 읽어서 확인할 수 있다.**

## 28분

적용하고 화면을 열었다. 아니었다.

기능은 목록대로 다 있었다. 그런데 이 블로그에 쓰고 싶은 얼굴이 아니었다. 색, 여백, 글자 크기, 목록에서 글 하나가 차지하는 넓이. 이런 건 기능 목록에 안 적혀 있고 스타 수로도 안 나온다.

교체 커밋이 28분 뒤에 찍혔다.

```
16:14  feat: AstroPaper 6.1.0 테마 적용
16:42  feat: AstroPaper -> AstroWind 테마 교체
```

**디자인은 목록으로 판단할 수 없다.** 당연한 말인데, 나는 기능 표를 채우고 버전 호환성을 확인하면서 결정을 다 했다고 생각했다.

## 두 번째는 데모부터 봤다

다시 고를 때 순서를 바꿨다. 데모 사이트를 먼저 열고, 마음에 드는 것만 남긴 다음, 거기서 조건을 걸렀다.

조건은 하나만 봤다. **Astro 버전이 지금 환경과 맞는가.**

- Astro Sphere — Astro 4. 제외
- Fuwari — Astro 5. 제외
- AstroWind — Astro 7.3.1 + Tailwind 4. 지금 쓰는 것과 정확히 같다

버전이 어긋나면 포팅이 따라붙는다. 디자인이 마음에 들어도 그건 다른 작업이 된다.

## 갈아엎는 값

두 번째 교체는 194개 파일이었다.

AstroWind는 원래 마케팅 사이트 템플릿이다. 랜딩 6개, 홈 4개, 가격표, 서비스 소개, 문의, 약관, 개인정보처리방침, CMS 설정이 딸려 왔다. 전부 지웠다. 홈은 559줄짜리 마케팅 랜딩이었는데 글 목록으로 바꿨다.

frontmatter도 두 번 옮겼다.

```
내가 만든 것    →  AstroPaper      →  AstroWind
pubDate            pubDatetime        publishDate
description        description        excerpt
src/content/posts/                    src/data/post/
```

글이 한 편뿐일 때라 손으로 고치면 끝이었다. 열 편이었으면 스크립트를 짰을 것이고, 그건 이 결정의 값이 그만큼 커졌다는 뜻이다.

빌드도 두 번 깨졌다. 홈에서 목록 헬퍼를 쓰면 `/blog` 경로에만 맞는 파라미터를 찾다가 죽었고, 제목 템플릿이 홈에서 한 번 더 붙어 제목이 중복됐다. 둘 다 테마의 전제를 그대로 가져다 쓰면서 생긴 것이다.

## 롤백 지점을 먼저 만들었다

두 번 다 갈아엎기 전에 브랜치를 남겼다. 지금도 있다.

```
backup-before-astropaper
backup-astropaper
```

99개 파일, 194개 파일이 한 번에 바뀌는 작업이었다. 되돌릴 방법이 `git reset`밖에 없으면 중간에 판단이 흔들린다. **돌아갈 곳이 있으면 과감하게 갈아엎을 수 있다.** 28분 만에 결정을 뒤집을 수 있었던 것도 그래서다.

## 기준을 이렇게 바꿨다

무엇을 고르든 **결과물을 먼저 보고, 그다음에 조건을 건다.** 순서가 반대면 조건을 다 만족하는 답을 골라놓고 마음에 안 드는 상태가 된다.

기능 목록으로 판단할 수 있는 건 "이게 되는가"뿐이다. "이게 내가 원하는 것인가"는 안 나온다. 두 질문을 같은 근거로 답하려 한 게 잘못이었다.
